# Le Quartier

A French-learning game for your phone. You move into a Paris neighbourhood. Each place is a station on a metro line, and each station has a neighbour to befriend.

**Play it:** open `index.html` in Safari (or host the repo with GitHub Pages), then tap Share › Add to Home Screen. It then runs full screen like an app.

## What's inside
- 16 stations from A1 to B1: greetings, ordering, family, shopping, directions, health, routines, restaurants, past tenses, travel, memories, pronouns, future and conditional, the subjunctive, and spoken slang.
- Seven exercise types: new-word cards, multiple choice, listening, typing in French, sentence building, dictation and speaking.
- Spaced repetition. Every word comes back right before you'd forget it, and mistakes return at the end of the lesson.
- A conversation with each neighbour once you finish their three lessons. Friendship hearts go up as you progress.
- A verb lab: 50 verbs in 6 tenses, with audio and drills.
- Skip tests that let you jump ahead when you already know a station (80% needed).
- No lives and no paywall.
- In the Claude-hosted version, a friends leaderboard and progress sync across devices.

## Develop
Source lives in `src/`. Run `./build.sh` to rebuild `index.html` (standalone app) and `dist/quartier.html` (Claude artifact version).
